Objetivo:</br>
Implementação, em Java, a heurísticas de inserção para o Traveling Salesman Problem (TSP).</br>
Neste trabalho, o foco não é encontrar necessariamente o circuito (tour) ótimo, mas sim comparar duas heurísticas clássicas de construção de circuitos (tours):
- nearest insertion
- smallest insertion
